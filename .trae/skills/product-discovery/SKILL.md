# Product Discovery

## Purpose
Convert high-level requests into executable product requirements for engineering delivery.

## Invoke When
- User says goals are unclear or changing.
- A feature request needs MVP scope.
- You need measurable acceptance criteria before implementation.

## Workflow
1. Restate target user and business outcome.
2. Split demand into must-have, should-have, optional.
3. Define user flow and edge cases.
4. Output acceptance criteria and non-goals.
5. Provide delivery checkpoints for design, backend, frontend, and test.

## Quality Bar
- Each criterion must be testable.
- Scope must avoid hidden dependency expansion.
- Terms should be stable across product, design, and engineering.
