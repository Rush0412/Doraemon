# UI UX Refiner

## Purpose
Make interfaces clearer, faster to operate, and visually coherent across devices.

## Invoke When
- Complex pages need hierarchy and interaction optimization.
- Design language is inconsistent across components.
- You need better mobile and desktop behavior.

## Workflow
1. Audit key user journeys and task completion cost.
2. Rebuild page hierarchy by priority and frequency.
3. Standardize spacing, typography, status colors, and controls.
4. Improve empty, loading, and error states.
5. Validate accessibility and responsive behavior.
